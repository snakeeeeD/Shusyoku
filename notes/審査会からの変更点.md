# Think or Sink：前回の審査会（2026-10-10ごろ）からの変更点

※ 審査会の日付は10月10日ごろとして整理（審査コメントのメモは10月11日）。エディタ群（10月10〜11日に作成）が審査会より前なら、「指摘への対応」から外す。

## 1. 審査での指摘への対応

| 指摘 | 対応 |
|---|---|
| 敵ごとの範囲を点滅させては？／右上の敵のウィンドウをもっと色で分ける | 敵1体ごとに識別色を出現時に決め、攻撃範囲・足元・右上の窓の枠・選択表示を同じ色で揃えた。何もしていない時は範囲を点滅させ、重なったマスは色を順に入れ替える。カーソルを合わせた敵の範囲だけを強調し、他の敵の範囲は薄くする |
| 敵が2体いると誤操作が多い／「こいつが選ばれている」を分かりやすく | 「光っている敵」と「実際に当たる敵」を同じ関数で決める形に統一（攻撃の対象予測→窓→マウス下→選択の優先順）。狙いの確定は150ms止まってから。攻撃範囲に敵が1体だけなら、空きマスにカーソルがあっても自動でその敵を攻撃 |
| カードを泳がせない方がいい | 手札のカードがマウスについてくる動きをやめ、使用ラインを越えたら全カード共通で中央に固定。狙う間はカメラが狙い先へ寄る |
| チュートリアルの文字が多い | 30ページ→7ページに削減。残りは、その状況が初めて起きた時だけ出る「その場ヒント」に（例：敵の範囲に入った、エナジーが0になった） |
| 重要なもの（HPなど）は集めて、他は目立たせない | 自分の状態（エナジー・HP・ブロック）を左下の1つの窓に集約。上部の帯は配置を変えず、HP・歩数・層・ゴールド・マップ・デッキをアイコン化して見た目だけ整理 |
| イベントがチープ | イベント画面を窓＋布バナーに作り直し。選択肢を「行動／結果」の2段で表示。結果画面で、受け取った素材・カード・レリックを一覧表示し、ダメージは画面の揺れとHPバーの減少で見せる |
| 面白さが5分で分かるループを！ | タイトルに「クイックプレイ（約5分）」を追加。斬撃・毒・罠の3デッキから選び（中身と説明を確認できる）、3戦とドラゴン戦を遊べる。デッキとレリックは各デッキ専用に固定 |
| 動画や資料を用意しては？ | トレーラー動画（約93秒）を作成：派手なカード3連→ゲーム概要→狙い／敵の色／合成／ボス戦／三つの層／クイックプレイ／エディター。資料も作り直し中 |
| 物量勝負なのにツールが無い | データ編集ツールを作成（エンカウント・敵の行動・カード・イベント・合成・レリック）。保存してその場で戦闘を試せる。存在しないIDなどの打ち間違いを、規則の表で一括検出する「参照切れチェッカー」も追加 |
| プログラマなら、データへのこだわりを | 上のツール群と、データ駆動の仕組み（ボスレリックの代償、クイックプレイの構成、イベントの結果もすべてJSON）をアピールの柱に |
| 勝利した時カードが残る／VICTORYの文字がずれている | 修正済み |

## 2. それ以外の追加・改善

### 新しいデッキの軸：聖地型（信仰）
「位置取り」というこのゲームの柱に直結する、オリジナルの軸として追加。**信仰はプレイヤーではなく「マス」にたまる**。

- **ルール**
  - カードでマスに信仰を刻む（1マス0〜10）。10になったマスは「聖域」
  - 自分が聖地に立つと攻撃力＋（信仰÷2）、聖域なら受けるダメージが半分
  - 自分のターン終了時、聖地に立っている敵は信仰と同じダメージを受け、そのマスの信仰は半分に減る（ブロック・弱体の影響を受けない固定ダメージ。マスに見えている数字がそのまま入る）
- **狙い**：序盤は聖地の10ダメージが大きいので、敵に踏ませる立ち回りが強い。後半はプレイヤーが強くなるので、敵に踏ませて信仰を削られるより、自分が乗り続ける立ち回りが強くなる。同じ仕組みで、ゲームの進行に合わせて最適な動き方が変わる
- **中身**
  - カード16枚：刻む（自分の足元／選んだマス／周り／攻撃が当たった敵の足元／移動前のマス）、審判（聖地の敵すべてに信仰×2）、奇跡（足元の信仰を全部払って周りに大ダメージ）、殉教（HPを払って即座に聖域）、浄化・神託（手札の呪いを消す）、パワー2枚（守護の誓い：聖地でターンを終えるとブロック／大聖堂：毎ターン周りのマスに信仰が広がる）、攻撃2枚（聖なる刃：足元の信仰1につきダメージ+1／裁きの剣：聖域に立っていれば2回攻撃）
  - レリック2個（全56個）：聖印（刻む量+1）、巡礼者の笠（移動するたび元のマスに刻む）
  - 合成素材：聖水の欠片（攻撃に付けると、当たった敵の足元に刻む。連撃と組むとヒットごとに刻む）
- **見た目**
  - マスに金の紋章（外周の10区切りが信仰の量だけ光る）と、呼吸するように明滅するオーラ。光の粒が立ちのぼる
  - 敵の攻撃範囲と重なっても見えるよう、紋章は加算合成で範囲の上から光らせる
  - 聖地に立つ敵の前に光の柱。焼かれる瞬間は金の光が弾け、聖域では画面が揺れる。専用の効果音つき
  - マスにカーソルを合わせると「信仰 N/10」と、次のターンに与えるダメージを表示
- **作り方（プログラマ視点）**
  - ルールの数値と判定は `Faith.h` の1か所に集約。刻む処理はすべてここを通るので、レリックの「刻む量+1」も1行で全カード・パワー・レリックに効く
  - 聖地の攻撃力アップと被ダメ半減は、立っているマスから毎フレーム付け外しする「バフ」として実装。カードの数字の色変わりやバフ一覧に、追加のコードなしで反映される
  - カード・レリック・素材・演出はすべてJSONのデータとして追加し、既存のエディタでそのまま編集・検査できる
- **バランス調整**：「巡礼」（移動しながら刻む）が普通の移動カードとして強すぎたため、移動を隣接1マスに。実際に通しで遊んだ結果、信仰だけでは火力が足りなかったので、「信仰は土台、火力は殴るカード」と位置づけ、信仰で強くなる攻撃カードを2枚追加

### 呪いカード
強いイベントのリターンに、デッキへ混ざる呪いをセットにした。

- **増殖**：手札にあるとターン終了時に捨て札へ増える
- **目くらまし**：手札にある間、敵の行動予告が見えなくなる（配っている途中も、引く可能性があれば隠す）
- **削除不可**：ショップやイベントでは消せない強い呪い。説明の先頭に赤字で表示
- **入手**：イベントの報酬の代償に加え、ボスレリック「覇道の炉」の代償にも。レリックの `extra` にカードを指定するだけで、代償としてカードを加えられる
- **見せ方**：イベントの選択肢やボスレリックにカーソルを合わせると、もらうカードの実物を横に表示。手に入れた瞬間は、暗い紫の光とともにカードが出現する

### 3層ボスの作り直し
- 本体・覚醒後・柱4本の絵を、画風をそろえて作り直し（柱は形と色で一目で見分けられるように、浮いた石柱に）
- **柱を倒すたびに、同じ色の鎖がボスから外れる**。あと何本か、どの柱を倒したかが絵で分かり、4本目で覚醒につながる。本体の絵に鎖の絵を重ねる汎用の仕組み（`Enemy::AddOverlay`）で実装
- 柱の攻撃が必中や盤面全体ばかりで避けられなかったので、縦一列・横一列・斜め・ひし形などに変更。ダメージは変えず、範囲で「避ける位置」を作った（全部合わせても安全なマスが12以上残ることを計算で確認）

### ゲーム内容
- ボスレリックを「代償つきの3択」に：ボスを倒すと、強い効果と代償（例：デッキに呪いが加わる、最大HPが減る）がセットになったレリック3つから選ぶ
- レリックを追加（イベント・ショップ・ボス用に計8個。全54個）。強すぎた「天駆の翼」を削除
- レリック全56個に専用アイコンを付け、レアリティで色分け。帯のレリックは窓つきで表示し、使用済みは暗く
- 「不落の城壁」が強すぎたので、ブロック全保持から「毎ターン15減って持ち越す」に変更
- 敵の攻撃96種類に、種類ごとの範囲演出（斬撃・打撃・毒・炎・魔法・岩）を割り当て。データ（enemies.json / effects.json）だけで変更できる
- バトルの盤面のマスを、層やボスごとの石板・金属パネルに（範囲を示す色はそのまま）
- 罠・灯火・起爆系で、自分のマスも選べるように
- 似た編成のエンカウントを整理（2層で3件削除）。イベントの選択肢に書かれていない結果を削除し、書いてある内容と結果を一致させた
- 3つの層ごとに、マップの背景を作り分け（森と草原／洞窟／古代遺跡）。紙の色が層ごとに暗くなる
- 3層ボスの覚醒演出に画面の揺れを追加
- 効果音を追加：被弾（ブロックで全部防いだ時は盾の音）・罠の設置・爆発・ショップでの購入・カード強化（3回鳴らす）。爆発の音はエフェクトのデータ（effects.json）に付け、見た目と同時に鳴る。同じ音の短時間の重なりは間引いて割れないように
- 戦闘開始時、プレイヤーが正面（顔が見える向き）を向いて立つように
- 回復のエフェクトを緑の十字に作り直し、プレイヤーの回復（カード・レリック・勝利時）でも表示
- 効果音を追加：足音（層ごとに芝生・土・床。バトルは1マス1回、フィールドは3歩）、ゴールド入手、信仰を刻む音、聖地で焼く音、デバフ、毒

### 2層ボス（オロチ）の作り直し
「HPの多い敵を殴っているだけ」という手応えだったので、狙う場所と時間の駆け引きを足した。
- **弱点**：頭はカードの攻撃が2倍、体は半分（毒・罠・聖地は等倍のまま。固定ダメージ系のデッキが不利にならないように）
- **光るウロコ**：頭まで行くのが大変なので、毎ターン、プレイヤーから4マス以内の体を1か所光らせる。殴ると2倍で、1回で割れる
- **噛みつき**：4ターンに1回、首を伸ばしてプレイヤーへ噛みつく。経路は予告の時点で決めて矢印で正確に表示し、経路の上に立っていても噛まれる。次のターンは首を戻す
- **脱皮**：カードの攻撃で一定量のダメージを受けるたびに脱皮し、巻きつく速さと攻撃力が上がる。脱皮するほど体が白くなる。殴るデッキは短期決戦、固定ダメージのデッキは耐えて長期戦、と攻め方で展開が変わる
- **移動不可・拘束**：ノックバックや引き寄せでは動かない。拘束を付けると巻きつきが止まる（メタカードとして拘束のカードを2枚追加）
- 体の描画を「頭の歩きに合わせて1マスずつ伸び縮み」に。移動の距離が長いほど速く動く
- 絵を描き直し、弱点と脱皮は途中チュートリアル（その場ヒント）で説明

### 床と敵の行動
- **床を4種類に**（炎・棘・沼・氷）。敵の行動ごとに、どの床を何ターン置くかをデータで決められる。踏んでも減らず、ターンで消える。マスの説明に残りターンを表示
- **沼**：上に立っている間、移動カードのコストが+1（コストは赤い数字で表示）
- 床を置く敵を追加（1〜3層に各床2体ずつ）、3層ボスの柱4本もそれぞれ違う床を置く
- **連続攻撃**を8体に追加（ダメージの合計は変えずに回数で分割）。行動予告に「5*3」のように回数を表示
- **大きい敵**：2×2や横2×1の敵を追加（ドラゴンに加え6体）。ノックバック・引き寄せ・突進・矢印・絵の位置を、すべて体の形全体で扱うように作り直した
- **召喚の位置**：子分を出すマスを予告の時点で決めて、攻撃範囲と同じ色で表示。そのマスに立っていると出てこない
- 動かず空振りしていた敵（エンバーウォーカー）に弱い攻撃を追加

### 新しいカード・レリック
- 機動型のカード5枚：移動するとブロック／隣の敵にダメージ／このターンの攻撃力が上がるパワーと、移動したマス数でダメージが増える攻撃（移動の効果を1か所に集め、敵を狙った突進でも発動するように）
- 拘束のカード2枚（縫い止め・束縛の鎖）
- レリック「浮遊のサンダル」：敵の床の効果を受けない

### 用語集（友達のプレイ感想から）
「聖地・聖域がカードだけでは分かりにくい」「用語集がほしい」という意見を受けて作成。
- 設定から開ける。基本・信仰・罠と床・バフ・デバフ・カード・敵の7分類
- 手書きの説明（`glossary.json`）に加えて、バフ・床・カードのキーワードは今ある説明文から自動で集める（説明を二重に書かない）。信仰の上限などの数値はコードの定数から入れるので、バランスを変えてもずれない
- 説明文の中の用語を金色にし、クリックでそのページへ移動。カードの説明も、マウスを説明に移すと残って、用語をクリックできる（敵の詳細の窓と同じ仕組み）
- オロチの弱点・脱皮は、2層ボスに着くまで載せない（ネタバレ防止）

### 見た目の統一
- **フォント**：Arial（日本語は代わりのフォント）から、同梱の M PLUS 1p（本文）と Noto Serif JP（見出し・ボタン・カード名）に。白い文字は少し温かい白に。文字の位置は、手で合わせた数値をやめて実際の大きさを測って決める形にした
- **アイコン**：バフ・デバフ42種と敵の行動13種を、レリックと同じ game-icons.net の絵柄で作り直し。丸い台座の色で種類が分かる（バフ＝青緑、デバフ＝赤、信仰＝金など）
- **窓の枠**：48pxの画像を192pxで描き直し、高解像度でもギザギザにならないように
- 罠の横に、置かれる罠の絵と効果を表示。バフやマスの説明の窓は、文の長さに合わせて大きさが変わる
- 自分と敵の足元のUIが重なる時だけ、自分のUIをずらす

### ツール
- 敵エディタで、演出をその場で再生できるように。攻撃範囲のマス目の上で、ゲームと同じタイミングで波のように流れる（`effects.json` の定義を読んで2Dで再現）
- カードエディタ・レリックエディタ・参照切れチェッカーを新しい項目（呪いの設定、代償で加わるカードなど）に対応

### 画面・UI
- ホバーで浮く動きを全画面で手札と同じ補間に統一。審査会で評判が良かった手札の滑らかさを、ボタンやカード一覧にも広げた（`HoverLift.h` の1か所で速さを調整できる）
- デッキ・マップ・設定などの窓を開いている間は、後ろの戦闘UIがカーソルに反応しないように
- 帯のマップ・設定ボタンは、ホバーで色を変えず浮くだけに統一
- 戦闘UIを描く順番を整理：敵のHPや行動予告が、中央のカード・捨てる画面・HPの窓・山札のボタンにかぶらないように
- 罠や灯火でも、狙ったマスがカーソルに合わせて持ち上がるように
- 罠や聖地の説明は、カード選択中は出さず、同じマスに0.5秒止めた時だけ出す（聖地が広がると出っぱなしになるため）
- 戦闘中の暗幕系の画面（山札・捨て札の一覧、カード選択、捨てるカードの選択）を、窓と布バナーで統一
- ショップ：敷物の背景、商品の下地、カード段とアイテム段の整理
- カード獲得画面：木の板の背景
- 敵の窓：文字に縁取り、行動予告の行数に合わせて高さを自動調整、詳細の窓は長い説明を折り返す
- カードの文字に縁取り、説明の折り返しを短く（行頭に「、」が来ないよう処理）
- 全画面の文字に縁取り（文字描画の1か所で自動付与。暗い色の文字には付けない）
- イベントでのカード選択：ホバー中は色を変えず金の縁で示す。強化では強化後のカードを横に表示
- レリックを入れ替えるイベントの画面を作り直し
- タイトル画面から設定を開けるように（タイトルでは「タイトルに戻る」を出さない）。左下の表示切替ボタンを「設定」に置き換え
- 設定画面・タイトル画面の文字を、ボタンの枠の中央にそろえる
- 上部の帯（マップ・アイテム・デッキ・設定）と設定画面のボタンを、カーソルを合わせると少し持ち上がるように（クリックの判定は元の位置のまま）

### 不具合の修正
- 敵の範囲の点滅や、レアカードのキラキラが約12秒ごとに途切れる（アニメ用のタイマーを巻き戻していたのが原因）
- 山札一覧のクリック位置が15〜20pxずれる（描画と判定の矩形を共通化）
- マップなどの「戻る」を押すと、ターン終了も押されてしまう
- タイトルに戻った時、ボタンが効かないことがある（休憩・イベントを開いたまま戻ると入力が止まっていた）
- チュートリアル中にレリックが発動して、説明とかぶる
- 最初のチュートリアルより先にヒントが出る
- 3層ボスの覚醒演出中に画面が揺れていなかった（演出用のカメラに揺れが足されていなかった）
- 戦闘開始時にプレイヤーが横や奥を向いてしまう（置いた瞬間を「移動」と判定していた）
- 移動カードを素早く振ると、通過中のマスへ暴発する（誤爆防止のチェックが移動だけ抜けていた。狙い確定を全カード0.2秒に統一）
- とどめのカードに捨てる効果があると、捨てる画面と勝利バナーが重なる
- 棒立ち防止の移動が引き寄せと同時に動いて、敵とプレイヤーの動きが重なる
- ブロックを持ち越す手段を重ねると、毎ターンブロックが増える
- 聖地の焼きダメージが、敵のブロックや弱体で表示の数字とずれる（固定ダメージに変更）
- デストラクションなどの時間差の演出と画面の揺れが、次の戦闘へ持ち越される
- オロチの光るウロコへ突進するとゲームが落ちる（狙ったマスではなく頭の位置へ斜めに進み、盤面の外へ出ていた）
- 引き寄せで体にめり込む・頭だけが動く（ボスのマスを敵として見ていなかった）
