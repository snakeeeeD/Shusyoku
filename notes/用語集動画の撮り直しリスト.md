# 用語集動画の撮り直しリスト（プレイヤーの絵の差し替えに伴う）

2026-11-09 作成。今ある用語集の動画 26 本は、すべて前のプレイヤー（青い勇者）が映っているので、全部撮り直す。

## 流れ

1. デバッグ画面の Encounter の **Template** で、下の「テスト戦闘」を選んで「Reload & Reset」（エンカウントエディタから id を選んでもよい）
2. **F9** で録画開始 → 見せたい場面を演じる → もう一度 **F9** で停止（`GameEngine/Recordings/` に保存される）
3. 録った動画をこのチャットに渡す → Claude が切り出して `Assets/Video/gloss_*.mpg` を**同じ名前で上書き**する
   - 名前が同じなので、用語集のデータ（glossary.json）は変えなくてよい
   - 切り出しは 16:9 → 640x360、mpeg1。前と同じ規格

撮影のコツ：録画中はデバッグ窓（ImGui）を閉じる。説明ウィンドウを映したくない場面は、デバッグ窓の「説明を隠す」を使う。
